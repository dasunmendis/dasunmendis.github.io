## 🚀 Local Development Setup

To run and preview the portfolio locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/dasunmendis/dasunmendis.github.io.git
   cd dasunmendis.github.io
   ```

2. **Serve the static files** (choose any preferred method):
   - Using Node.js `serve`:
     ```bash
     npx serve -l 3000
     ```
   - Using Python:
     ```bash
     python -m http.server 3000
     ```
   - Using VS Code: Right-click `index.html` and select **"Open with Live Server"**.

3. **Open in your browser**:
   Navigate to `http://localhost:3000`.
